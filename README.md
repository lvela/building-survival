# Building Survival

A 3D VR escape game built with Three.js and WebXR. You're a passenger on a plane that crashes into a tower. Get down all 10 floors, past fleeing coworkers and debris raining off the building, and out the lobby doors before it collapses behind you.

**Play:** open `index.html` in a browser, or in a WebXR headset browser (such as the Meta Quest Browser) and press **Play in VR**.

- Screen: WASD move, mouse look, Shift sprint, Space jump, C crouch, Enter skip intro
- VR: left stick move, right stick snap turn, grip sprint, A/X or trigger jump, crouch for real
